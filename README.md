## 🚀 Featured Projects

### 🤖 [CodeSage](https://github.com/BhaveshNikam09) — LLM Agent for Automated Code Review & PR Analysis
> `Python` `LangChain` `GitHub API` `OpenAI API` `Prompt Engineering`

An LLM-powered agent that integrates with GitHub pull requests to auto-generate bug reports, flag anti-patterns, and suggest fixes.
- 🧠 Chain-of-thought prompting improved bug detection precision by **~35%** over zero-shot baseline
- 📚 LangChain embeddings index entire repo for cross-file reasoning (enterprise RAG pattern)
- 🎯 Targets **60% reduction** in manual review time per PR
- 📄 **[Published Research Paper — IISTJ Vol. 2, Issue 5, May 2026](https://iistj.org/article.php?paperid=120426)**
